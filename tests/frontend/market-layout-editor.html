Element anklicken und verschieben. Am türkisfarbenen Eckgriff die Größe ändern. Texte, Positionen und Größen rechts bearbeiten. Untermenüs über „Menü öffnen“ oder die Menüauswahl wechseln. Doppelklick auf das Info-Icon zeigt die Hilfe. Kein Zugriff auf echte App-Daten.

Vorschau

Beim Größenwechsel bleiben die Positionen absichtlich erhalten. So siehst du, wo Platz fehlt. Das endgültige responsive Verhalten wird später umgesetzt.

Strg-/Umschalt-Klick fügt Elemente hinzu oder entfernt sie aus der Auswahl. Esc oder ein Klick auf die freie Vorschaufläche hebt die Auswahl auf. Ausgewählte Elemente gemeinsam ziehen, mit Pfeiltasten bewegen oder löschen. Eckgriffe ändern weiterhin nur das jeweilige Element.
